## Connection strings

- ConnectionStrings.com: https://www.connectionstrings.com/

Connection string examples from external sites must be adapted to the installed provider version, process architecture, authentication model, and security requirements.

## Security reminder

Before publishing examples, issues, or logs, remove:

- passwords,
- access tokens,
- private server names,
- personal data,
- complete production connection strings.
