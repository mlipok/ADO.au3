# ADO.au3

ADO.au3 is an AutoIt UDF for working with databases through Microsoft ActiveX Data Objects (ADO).

This repository preserves the latest known public beta release of **ADO.au3 UDF**:

- Version: `2.1.21 BETA`
- Published: November 20, 2025
- Original download page: https://www.autoitscript.com/forum/files/file/389-adoau3-udf/

The repository import is intended to preserve that public release as a GitHub-hosted baseline for future maintenance, documentation cleanup, and further development.

## Authors and contributors

ADO.au3 is maintained by mLipok and preserves the AutoIt community work and discussion related to the ADO.au3 UDF.
